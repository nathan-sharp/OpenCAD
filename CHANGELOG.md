# Changelog

All notable changes to the OpenCAD repository should be documented in this file.

## 1.0 - 2026-10-15

- officially released OpenCAD Interchange Standard (OCIS) version 1.0
- transitioned specification document from Working Draft to Final Standard
- finalized roadmap tasks including multi-implementation interoperability proofs
- updated version references across all project schemas, examples, and parsers

## 0.1 - 2026-03-14

- clarified repository status as a public working draft
- aligned contribution and repository licensing documentation
- added governance, maintainer, and code of conduct documents
- fixed schema consistency issues in the assembly format
- aligned example files and cross-file references
- added automated validation for schemas and examples
